# Что осталось перенести

Список собран сверкой: все строки интерфейса `YTLoc(@"…")` из iOS-исходника
против `loc("…")` в порте. Из 255 строк оригинала в порте не встречаются 129.
Часть расхождений — просто иные формулировки, остальное перечислено ниже.

Сверку можно повторить: `scratchpad/audit.py`.

## Страница ролика

- [x] **Описание.** Нажатие по названию открывает лист «Описание»
      (`openDescription`, `_descriptionSheet`). Сейчас название не нажимается.
      Строки: «Описание», «Описания у ролика нет».
- [x] **Карточка «Главы».** Сворачиваемая, с названием текущей главы
      в заголовке и списком внутри (`_chapterCard`, `toggleChapters`).
      Сам разбор глав уже есть — нет карточки.
- [x] **Очередь и плейлист** (`applyQueue:`, `_queueCard`, `toggleQueue`) —
      та самая полка, которой не хватает у роликов из подборок.
      Строки: «Следующий в плейлисте», «%ld из %lu».
- [x] **Первый комментарий под роликом.** Есть кнопка, открывающая экран;
      в оригинале под действиями стоит карточка с первым комментарием
      (`applyComments:`). Строки: «Комментариев нет»,
      «Комментарии к этому видео отключены».
- [x] **Написание, ответы и правка комментариев** (`YTCommentsList`).
      Строки: «Добавьте комментарий», «Ответ %@», «Ответы (%@)»,
      «Правка своего комментария», «Комментарий не принят»,
      «Чтобы писать комментарии, войдите…».
- [x] **Скачивание с страницы ролика.** Кнопка в ряду действий с процентами.
      Строки: «Скачать не выйдет», «Собираем файл…», «Скачано %.0f%%»,
      «Качество для скачивания».
- [x] **Меню плеера урезано:** нет «Перезагрузить видео» и сдвига субтитров
      («Сдвиг субтитров», «Раньше на 0,25 с», «Позже на 0,25 с»,
      «Вернуть обычный (+2,00 с)»).
- [x] Заголовок «Похожие видео» над списком.
